它能帮你做什么

系统设置里顾不到的那几件小事，这里都补上了。

单独开关某台显示器

关掉之后，这块屏会从桌面布局里退出去，窗口自动挪到还在用的屏幕上。想用回来的时候，菜单底部留着入口，点一下它就回来了。

亮度滑块放在一级菜单

打开菜单就能拖，不用先展开一层。内置屏用系统亮度接口，外接屏走 DDC/CI，写入做了节流，不会把通道写坏。

HiDPI 一键切换

分辨率不用变，只把渲染精度提上去，字和图标会更细腻。有些屏没有同样尺寸的高分档位，那就退到最近的一档，菜单标题里会先告诉你要切到哪儿。

分辨率切换

默认只列常用的几个档位，是 HiDPI 的会标出来。想看全部，菜单最下面有个「显示所有分辨率」的开关。

DDC 通道自检

亮度怎么都调不动的时候，可以在终端里跑一次 --ddc-test。它会把读、写、复读、恢复走一遍，读数没变，就说明确实没写进去。

纯 Swift，不联网

整个应用用 AppKit 和 CoreGraphics 手写，没有第三方依赖，也没有内核扩展。不申请系统权限，不联网。代码量不大，想读的话一个下午能过一遍。

下载 Display Master

下载后双击打开，把左边的 App 拖到「应用程序」上就装好了。第一次启动 macOS 会拦一下，因为它没有 Apple 开发者账号的签名，照着提示放行一次就行。

应用没有 Apple 开发者签名（一份签名一年 99 美元，这个免费小工具就不花这笔钱了）。拖进「应用程序」以后，右键点它、选「打开」，弹窗里再点一次「打开」，往后就正常了。详细步骤和另外两种办法都写在安装说明里。

也可以自己编译，需要先装 Xcode 命令行工具：

终端
# 克隆仓库
git clone https://github.com/906351854/DisplayMaster.git
cd DisplayMaster

# 编译 release、组装 .app、装到「应用程序」并重启运行中的实例
./build.sh

# 只想编译不想安装，就换成：
# ./build.sh --no-install
