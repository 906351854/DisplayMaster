它到底能做什么

系统「显示器」设置面板管不到的那些事，这里一件件补上。

单独开关某台显示器

真的把屏幕从桌面布局里移除，窗口会跟着重排 —— 不是盖一层黑。被关掉的屏幕会留在菜单底部，点一下就能开回来。

亮度滑块放在一级菜单

打开菜单就能拖，不用先展开一层。内置屏走系统亮度接口，外接屏走 I²C 上的 DDC/CI，写入带节流保护。

HiDPI 一键切换

在同一个逻辑分辨率上切换渲染倍率。如果没有同尺寸的变体（内置 Retina 屏就是如此），会退到最接近的一档，并提前在菜单标题里写清楚。

分辨率切换

默认只列常用档位，HiDPI 的会标注出来。想要完整列表，菜单最下面有「显示所有分辨率」开关。

DDC 通道自检

亮度调不动又不知道卡在哪？命令行跑一次 --ddc-test，从读、写、复读到恢复全程验证，读数不变就是没真的写进去。

纯 Swift，不联网

AppKit + CoreGraphics 手写，没有第三方依赖、没有内核扩展、不需要任何授权、不发起网络请求。想审计代码，整个仓库读一遍用不了多久。

打不开？很可能是 Gatekeeper 拦的

这个应用没有 Apple 开发者签名（那需要每年 99 美元，一个免费小工具没必要）。把 App 拖进「应用程序」后，右键点它 → 选「打开」→ 再点一次「打开」，之后就正常了。详细步骤和命令行做法见安装说明。

或者自己从源码编译（需要装了 Xcode 命令行工具）：

终端
# 克隆仓库
git clone https://github.com/906351854/DisplayMaster.git
cd DisplayMaster

# 编译 release、组装 .app、装到「应用程序」并重启运行中的实例
./build.sh

# 只想编译不想安装，就换成：
# ./build.sh --no-install
